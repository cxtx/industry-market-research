# 范围锁定与任务受理

## 最小受理信息

行业或细分领域名称是唯一必需的初始输入。检索前确认三项会改变分母的条件：

1. **行业边界**：卖什么、面向谁、是否包含上下游、线上与线下是否都包括。
2. **地理范围**：全球、国家、省市或城市群。用户未指定时必须询问，不能因语言自动假定国家。
3. **规模口径**：营收、终端销售额、GMV、出货量、产量、保有量、用户数或其他行业惯用口径。

如果行业术语有公认定义，可提出建议定义供用户快速确认。若只有年份、报告格式或品牌数量未指定，使用默认值而不扩大访谈。

## 默认值

| 项目 | 默认值 |
|---|---|
| 历史期间 | 最近 5 个完整年度，加最新可得期间 |
| 趋势期间 | 未来 3—5 年 |
| 报告深度 | 标准版 |
| 竞争范围 | 主要品牌 Top 10；不足时覆盖全部可验证品牌 |
| 中国市场币种 | 人民币，保持名义口径 |
| 国际比较 | 保留原币，另给可追溯的统一币种换算 |
| 预测方式 | 低、基准、高三种情景；证据不足时仅做定性趋势 |

## 范围声明

在报告开头写明：

- 纳入和排除的产品或服务。
- 价值链位置以及 B2B、B2C 或 B2G 范围。
- 地理和时间边界。
- 市场规模与市场份额的统一分母。
- 币种、含税状态、名义或实际价格口径。
- 品牌、公司、集团和业务分部的对应关系。

## 研究矩阵

开始浏览前建立简短矩阵：

| 研究问题 | 指标 | 地区/期间 | 首选原始来源 | 交叉来源 | 当前状态 |
|---|---|---|---|---|---|

状态使用 `待检索`、`已获得`、`口径冲突`、`需估算`、`不可获得`。先覆盖用户关心的核心指标，再补充产业链和趋势背景。

## 何时询问，何时继续

必须询问：

- 地理范围缺失。
- 同一行业名称对应明显不同的产品或统计分类。
- 用户指定的指标可能使用互不兼容的分母。

可以继续并披露假设：

- 没有指定年份、报告深度、品牌数量或输出币种。
- 某一非核心指标公开资料不足。
- 某品牌是公司、集团或业务分部，但可通过范围声明清楚区分。
