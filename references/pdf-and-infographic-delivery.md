# PDF 与核心指标信息图交付规范

## 适用情形

以下任一条件满足时读取并执行本规范：

- 生成完整行业市场调研报告；
- 用户明确要求 PDF、信息图、核心指标图或可视化摘要；
- 用户提供现成 PDF 调研报告，要求插入、补充或更新核心指标信息图。

用户明确只要文字、Markdown 或结构化数据时，可以不生成 PDF 和信息图。

## 新报告模式

1. 先完成 `report.md`、`data.csv`、`evidence.csv` 和必要的计算文件，并通过基础校验。
2. 从执行摘要中选择 5—8 个 A—C 级指标。优先覆盖市场规模、增速、竞争集中度、渠道或区域结构、代表企业经营指标和前瞻触发条件；不得使用 D 级、不可获得或尚未进入证据台账的数字。
3. 生成 `盐焗小调-<地域>-<主题>-核心指标信息图-<YYYY-MM-DD>.png`。信息图应包含：
   - 报告主题、研究地域、数据期间和报告截至日期；
   - 3—6 个醒目的核心指标卡；
   - 最多 2 个紧凑图表，用于表达趋势、结构或对比；
   - 必要的单位、分母、口径和数据性质提示；
   - 简短来源行，例如“来源：本报告 data.csv 与 evidence.csv”。
4. 在 `report.md` 的“执行摘要”或“核心结论”正文之后、下一节二级标题之前插入：

   ```markdown
   ![核心指标信息图](盐焗小调-<地域>-<主题>-核心指标信息图-<YYYY-MM-DD>.png)
   ```

5. 将报告渲染为 `盐焗小调-<地域>-<主题>-市场调研报告-<YYYY-MM-DD>-v<版本>.pdf`；未指定报告版本时使用 `v1.0`。信息图应完整出现在报告前部，不能先于核心结论，也不能被裁切、跨页或缩小到无法阅读。
6. 使用 PDF 能力逐页渲染并目视检查。发现中文乱码、数字错误、图像模糊、分页异常或遮挡时，修正后重新渲染。

## 信息图设计与数据规则

- 所有数字必须逐项回查 `data.csv`；展示值允许做清晰标注的单位换算或四舍五入，但不得改变结论。
- 每个数字至少能判断其单位和期间；份额、增长率、平均值和利润率必须能判断分母或统计口径。
- 信息图是执行摘要的视觉压缩，不新增未经正文和证据台账支持的事实、排名或预测。
- 同一张图不混用自然年与财年、名义值与实际值、集团与品牌、销售额与 GMV，除非显式标注差异。
- 使用简洁、专业、高对比度的版式；中文正文在 PDF 的实际阅读尺寸下必须清晰。
- 不添加无授权品牌标识、水印或装饰性伪数据。图表优先表达关系，不堆砌大段正文。
- 报告封面和信息图左上角使用文字品牌“盐焗小调”，可附口号“调研有据，洞见有声”；不得虚构机构资质或第三方背书。
- 可使用环境中的图像生成能力制作视觉稿；生成后必须核对文字和数字。若一次定向修正后仍无法保证标签准确，改用确定性的图表、矢量或幻灯片方式生成。

## 现成 PDF 模式

1. 保留用户原始 PDF，不覆盖、不原地修改。
2. 使用 PDF 能力提取文本和页面映射，定位“执行摘要”“核心结论”“Executive Summary”或“Key Findings”。
3. 只从该 PDF 及用户同时提供的证据中提取核心指标。除非用户明确要求补充调研，不联网新增数字，也不把推测写入信息图。
4. 若存在可编辑源文件，在源文档的核心结论正文后插入信息图并重新渲染。
5. 若只有 PDF，制作与原报告页面尺寸相容的独立信息图页，并插在最后一页执行摘要或核心结论之后。不得通过覆盖坐标的方式破坏原页内容。
6. 若无法识别核心结论章节，将信息图页放在封面和目录之后的第一个合理位置，并在交付说明中披露实际位置。
7. 输出 `盐焗小调-<原文件名>-核心指标增强版-<YYYY-MM-DD>.pdf`；信息图源文件另存为 `盐焗小调-<原文件名>-核心指标信息图-<YYYY-MM-DD>.png`。原文件名已经以“盐焗小调-”开头时不重复添加品牌前缀。
8. 逐页渲染合并后的 PDF，核对页序、页面尺寸、方向、字体、清晰度和原报告内容完整性。

现成 PDF 模式不强制创建 `report.md`、`data.csv` 和 `evidence.csv`；但应保留一份简短的指标摘录或制作说明，记录图中数字对应的原页码。若用户要求把现成 PDF 升级为完整可复算研究包，则回到新报告模式补齐结构化文件。

## 交付前检查清单

- 信息图位于核心结论之后、主体分析之前；若不是，已说明原因。
- 图中每个数字均与报告或结构化数据一致，单位、期间、地域和分母清楚。
- 图中只使用 A—C 级指标，或在现成 PDF 模式中能定位到原始页码。
- PNG 可正常打开，PDF 可正常解析；图像没有裁切、变形、乱码或模糊。
- 原始 PDF 未被覆盖，输出文件名符合约定。
- 新报告已运行：

  ```text
  python <skill-dir>/scripts/validate_research_package.py . --strict --require-pdf-visual \
    --pdf-file "<盐焗小调正式PDF文件名>" \
    --infographic-file "<盐焗小调信息图文件名>"
  ```
